# 赣企科技集团多页面门户改造设计规格

**日期：** 2026-08-20  
**项目：** 赣企科技集团官方网站  
**技术栈：** Vite + React + Tailwind CSS + JavaScript  
**视觉目标：** `design-references/ganqi-selected-homepage-direction.png`  
**结构参考：** 行云集团官网首页与栏目页；只借鉴成熟集团门户的信息架构、页面节奏与交互方式，不复制其品牌、文案或素材。

## 1. 建设目标

把现有单页集团首页重构为中英双语、多路由的 B2B 政企商务集团门户。首页负责集团概览与业务分流，所有一级导航与下拉子项均跳转至独立 URL，不再把首页锚点当作网站主导航。

网站只用于品牌展示、业务介绍和商务询盘，不建设商城、商品交易、购物车、支付、会员或后端管理功能。询盘表单仅实现前端 UI、校验和成功反馈。

## 2. 品牌与内容边界

- 赣企出海是首页和集团业务表达的主品牌。
- 亚税通是旗下企业，不与赣企出海并列为集团首页主品牌。
- 集团事实、业务、时间线、文化、战略、荣誉和数字以集团简章及用户提供的资料为唯一依据。
- 已确认数字仅使用：服务 10,000+ 企业、覆盖 100+ 城市、500+ 海外合作机构。
- 缺少正式资料的板块使用中性状态：“内容将在集团正式资料确认后发布”，不得生成看似真实的奖项、新闻、合作单位、地址或统计数据。
- 已有企业宣传片继续用于首页集团介绍模块。

## 3. 集团总站与业务子站边界

### 3.1 集团总站

集团总站负责集团介绍、战略、业务矩阵、旗下企业、全球网络、新闻与联系入口。八大业务在首页与业务总览页只做摘要和分流。

### 3.2 国际会展子站

国际会展属于“赣企出海国际会展（江西省）有限公司”。集团总站不编写会展业务详情；所有“国际会展”入口跳转到环境变量 `VITE_EXHIBITION_SITE_URL` 指定的外部子站，并使用安全的新窗口属性。

### 3.3 企业服务与国际教育子站

- `/companies/enterprise-services`：赣企出海创业服务（江西省）有限公司独立业务站。
- `/companies/education`：赣教出海国际教育科技（江西省）有限公司独立业务站。
- 两个业务站保留自身页头、首屏、服务体系、流程、项目实景与页脚。
- 两个业务站 Logo 均返回集团首页 `/`。
- 集团总站通过业务矩阵和旗下企业页进入两个业务站，不在集团首页重复做其完整业务详情。

## 4. 路由架构

### 4.1 一级页面

| URL | 页面 | 用途 |
| --- | --- | --- |
| `/` | 集团首页 | 集团总览、业务分流、品牌展示 |
| `/about` | 集团介绍 | 集团定位、简介、使命愿景、核心价值观 |
| `/history` | 发展历程 | 展示 2018–2026 发展时间线 |
| `/culture` | 企业文化 | 使命、愿景、价值观与组织文化 |
| `/honors` | 荣誉资质 | 仅展示简章确认的荣誉与资质 |
| `/business` | 业务体系 | 四大高价值板块与八大海外业务总览 |
| `/strategy` | 北斗七星战略 | 战略模型的集团层摘要与七个环节 |
| `/companies` | 旗下企业 | 集团企业矩阵及进入各子站的入口 |
| `/global` | 全球网络 | 城市、合作机构和全球服务网络概览 |
| `/news` | 新闻中心 | 集团新闻与行业观察框架 |
| `/news/:slug` | 新闻详情 | 统一新闻详情模板 |
| `/contact` | 联系我们 | 联系信息、业务分流与前端询盘表单 |

### 4.3 导航行为

- 桌面端一级导航：`首页 / 关于集团 / 业务体系 / 旗下企业 / 全球网络 / 新闻中心 / 联系我们`。
- “关于集团”“业务体系”“旗下企业”“新闻中心”支持悬停和键盘聚焦下拉。
- 每个一级菜单标题本身也指向独立页面。
- 移动端使用菜单抽屉，分组展示一级与二级链接；打开时锁定背景滚动，支持关闭按钮和 Escape。
- 当前路由显示选中状态。
- 语言开关保持在同一路由切换中英文内容。
- 首页按钮可以进入独立页面；只有同一详情页内部的辅助导航允许使用锚点。

## 5. 首页楼层

首页严格采用选定视觉方向的节奏：深蓝主导、白色内容区、橙色行动色、大图和充分留白。

1. **透明/深色导航首屏**：全球化或真实海外业务大图；短标题“让中国企业，更好地走向世界”；一个主行动按钮。
2. **集团介绍与数据**：左侧企业宣传片，右侧集团简介、10,000+、100+、500+ 与“了解集团”入口。
3. **集团业务**：深蓝背景四张大图业务卡，对应四大高价值业务板块；点击进入业务总览或对应详情。
4. **服务优势**：左侧能力选项，右侧相关实景大图；选项切换内容但不改变 URL。
5. **国际会展重点入口**：使用已提供会展实景图，跳转外部会展子站。
6. **北斗七星战略摘要**：深蓝横向带状模块，进入 `/strategy`。
7. **旗下企业摘要**：展示集团层确认企业；企业服务、国际教育进入子站，国际会展进入外部子站。
8. **全球网络**：用集团确认的统计与真实业务照片表达全球覆盖，不虚构地图坐标。
9. **合作伙伴 Logo 墙**：授权 Logo 未提供前展示四类合作资源的中性文字位，不伪造 Logo。
10. **新闻中心**：一个重点新闻和两个常规新闻卡；无正式稿件时显示内容发布说明。
11. **商务合作 CTA**：进入 `/contact`，不直接依赖首页锚点。
12. **完整页脚**：关于集团、业务体系、旗下企业、新闻中心、联系入口、语言与版权信息。

## 6. 内页模板

### 6.1 通用栏目页

适用于集团介绍、企业文化、业务总览、战略、旗下企业与全球网络：

- 内页大图 Banner
- 面包屑
- 页面标题与一句摘要
- 栏目二级导航
- 2–5 个内容楼层
- 关联入口
- 商务合作 CTA

### 6.2 时间线页

发展历程使用年份索引和纵向时间线；仅渲染已确认的 2018–2026 条目。移动端改为单列时间线。

### 6.3 荣誉页

荣誉按年份或类型分组。未获得证书图片的荣誉只显示文字条目，不生成虚假证书图。

### 6.4 新闻页

- 新闻列表提供“集团新闻 / 行业观察”前端分类切换。
- 新闻详情使用统一图片、日期、正文和上一篇/下一篇框架。
- 未提供正式新闻时只显示一条明确的内容状态，不伪造稿件。

### 6.5 联系页

- 集团正式联系信息区。
- 业务类型分流。
- 前端询盘表单字段：姓名、公司名称、手机号/邮箱、意向业务、目标国家或市场、需求说明、隐私同意。
- 必填校验、邮箱/手机号基础格式校验、提交成功状态。
- 不发送网络请求，不承诺数据已保存。

### 6.6 业务详情页

未拥有独立子站的业务使用统一详情模板：业务价值、服务对象、核心服务、合作流程、相关实景、常见问题和询盘 CTA。正式业务内容不足时保留结构并显示资料状态。

## 7. 组件架构

- `siteMap`：中英文路由、导航、下拉与页脚的单一配置源。
- `pageContent`：集团内页与业务详情的中英文数据源。
- `GroupHeader`：桌面下拉、移动抽屉、当前路由与语言开关。
- `GroupFooter`：多栏目路由链接和版权区。
- `PageHero`：内页 Banner、面包屑和标题。
- `SectionHeading`：统一楼层标题。
- `GroupStats`：已确认集团数字。
- `BusinessShowcase`：四大板块和八大业务展示。
- `CapabilityTabs`：首页服务优势切换。
- `CompanyMatrix`：旗下企业及子站跳转。
- `NewsGrid` / `NewsDetail`：新闻列表和详情框架。
- `InquiryForm`：纯前端表单状态与校验。
- `PlaceholderNotice`：对缺少正式资料的统一透明说明。

页面内容和视觉组件分离；新增正式资料时优先更新内容对象，不修改页面骨架。

## 8. 视觉与响应式规则

- 主色：深海军蓝；内容底色：白与冷灰；行动色：赣企橙。
- 首页首屏和深色业务楼层使用白字；内页正文以深蓝标题和灰蓝正文为主。
- 圆角控制在 0–8px；阴影只用于视频、悬浮下拉和必要的层级。
- 动画仅限导航下拉、图片轻微缩放、选项切换和滚动进入；尊重 `prefers-reduced-motion`。
- 图片按原始比例分类：宽幅首屏/横幅、4:3 卡片、竖图成果位；不把竖图强裁成横图。
- 1440px 桌面以 1200–1240px 内容宽度为基准。
- 768–1023px 使用压缩网格；小于 768px 切换抽屉导航与单列内容。
- 移动端首屏文字不超过两层主标题与一句副标题，CTA 保持触控友好。

## 9. 错误与空状态

- 未识别路由显示集团风格 404，并提供返回首页和查看业务两个入口。
- 新闻 slug 不存在时显示新闻未找到状态，不回落到虚假文章。
- 图片缺失使用已有相关素材或隐藏图片位并保持排版，不显示破图。
- 外部会展地址未配置时使用本地开发默认地址；正式部署必须通过环境变量配置。

## 10. 验收标准

1. 一级导航和所有下拉项均使用独立 URL，不使用首页锚点充当主导航。
2. 中文与英文拥有相同路由和模块结构。
3. 首页与选定视觉目标在 1440px 下保持一致的信息节奏、色彩权重和空间层级。
4. 390px 移动端无横向滚动，抽屉导航、语言切换和表单可用。
5. 国际会展入口全部安全跳转外部子站。
6. 企业服务与国际教育子站保持独立页头并支持 Logo 返回集团首页。
7. 页面仅使用确认业务与数字；缺少资料时明确显示资料状态。
8. 表单前端校验和成功状态可操作，无后端请求。
9. 所有公开路由返回可渲染页面，未知路由进入 404。
10. 自动测试、生产构建、桌面与移动端视觉对比、导航交互和控制台错误检查全部通过。

## 11. 非目标

- 不建设商城、支付、会员、订单或商品管理。
- 不建设真实 CMS、数据库或表单后端。
- 不抓取或复制行云集团的图片、Logo、新闻或业务文案。
- 不生成未获确认的集团事实、荣誉、客户、合作机构或联系方式。
- 本阶段不部署到公网，不变更集团域名或服务器所有权。
