# 赣企科技集团首页基础框架设计

## 目标

在不修改根目录现有会展子站的前提下，建立独立的 Vite + React + Tailwind CSS 集团总站项目。首期只实现一个可运行、可响应、可切换中英文的首页，用于确认集团蓝橙政企商务风格。

## 页面范围

首页包含：全局导航、集团首屏、集团简介与核心数据、双品牌、四大高价值业务、八大海外业务、北斗七星战略摘要、旗下企业、合作伙伴占位说明、商务合作 CTA、页脚和悬浮咨询入口。

不包含：商城、支付、会员、后端表单、完整内页、展会列表及展会详情。国际会展入口只显示摘要并跳转会展子站；子站正式地址未提供时采用可配置常量并给出明确提示。

## 信息与品牌

- 文案、数据和业务命名来自《赣（寰）企出海丨亚税通公司简介.pdf》。
- 主视觉色为深海蓝与品牌橙，搭配白色和浅灰背景。
- 集团正式 Logo 尚未提供，首期使用文字品牌标识；现有 `公司logo.png` 属于会展子公司，不作为集团总站主 Logo。
- 合作伙伴 Logo 未提供授权素材，首期显示合作类别，不伪造具体合作方 Logo。

## 交互

- 中英文切换覆盖导航、按钮、标题和主要业务文案。
- 桌面端使用横向导航，移动端使用可展开菜单。
- 国际会展卡片带外链标识。
- 悬浮咨询按钮滚动至页面底部商务合作区域。
- 尊重 `prefers-reduced-motion`，动画只使用轻量淡入和悬停反馈。

## 验收标准

1. `npm run dev` 可启动，`npm run build` 成功。
2. 首页可在桌面和移动端正常排版。
3. 中英文切换、移动菜单、咨询锚点和会展外链行为可测试。
4. 页面不出现简章以外的业务和未经确认的数据。
5. 根目录会展子站文件保持不变。
